EPUB Studio Official User Guide & Operation Manual (v2.1.7)

웹 툴 주소: https://123494321.github.io/EPUB-creation-web-tool/  •  지원 기기: PC, 태블릿, 스마트폰 (100% 브라우저 구동)
🚀 3분 완성 퀵 스타트 (Quick Start Summary)
  1. 원고 불러오기: 상단의 📂 파일 불러오기 버튼을 눌러 TXT 파일을 엽니다.
  2. 목차 자동 생성: 본문에서 목차 패턴(예: 제1장 ...)을 드래그한 후 ✨ 목차 형식 분석을 누릅니다.
  3. 삽화 등록 (선택): 삽화 보관함에서 이미지를 추가하고 본문에 [IMAGE:파일명]을 삽입합니다.
  4. 전자책 출판: 우측 상단의 전자책 생성을 눌러 도서 정보와 표지를 설정하고 .epub 파일을 다운로드합니다.

1단계: 원고 파일 불러오기 (File Loading)

본 스튜디오는 소설, 에세이, 인문/학술서, 보고서, 매뉴얼 등 모든 형태의 텍스트(.txt) 파일을 지원합니다.

  • 상단 툴바의 [📂 파일 불러오기] 버튼을 클릭하여 소장 중인 원고 텍스트 파일을 선택합니다.
  • 초고속 인코딩 자동 감지: UTF-8(BOM 포함/미포함), UTF-16, CP949(EUC-KR) 등 어떤 인코딩의 파일도 글자 깨짐 없이 완벽하게 자동 분석하여 열어줍니다.
  • 22.6MB 무손실 가상 뷰포트: 80만 줄 이상의 방대한 대용량 원고도 1초 만에 로드되며 렉 없이 부드럽게 스크롤됩니다.

2단계: 목차 생성 및 관리 (Table of Contents)

2.1 '목차 형식 분석' (원클릭 자동 완성)

  • 본문 에디터에서 목차의 기준이 될 문장(예: 제1장 프롤로그 또는 Chapter 01, 1화 등)을 마우스나 터치로 드래그하여 선택합니다.
  • 상단의 [✨ 목차 형식 분석] 버튼을 클릭합니다.
  • AI 정규식 분석 엔진이 백그라운드에서 전체 본문을 1초 만에 전수 검색하여 일치하는 모든 목차를 자동으로 추출·등록합니다.

2.2 '선택영역 목차 추가' (수동 등록)

  • 본문에서 목차로 지정하고 싶은 특정 문구를 드래그한 후 [➕ 선택영역 목차 추가]를 누르면 해당 줄 번호와 함께 즉시 목차에 추가됩니다.

2.3 목차 관리 도구 (아이디어 A 서브 툴바)

목차 탭 패널 내부의 서브 툴바를 통해 목차를 편리하게 관리할 수 있습니다:

  • 동기화 : 본문을 수정한 후 목차의 실제 줄 번호를 본문 위치에 맞춰 재정렬합니다.
  • 개별 해제 : 목록에서 선택한 특정 목차 항목만 삭제합니다.
  • 전체 삭제 : 등록된 모든 목차를 초기화합니다.
  • 목차 항목을 클릭하면 본문 에디터의 해당 위치로 0ms 즉시 점프합니다.

3단계: 삽화(이미지) 등록 및 본문 배치 (Image Library)

  • 우측(또는 모바일 삽화 탭)의 [+ 추가] 버튼을 눌러 전자책에 넣을 이미지(JPG, PNG, GIF, WebP 등)를 복수 선택하여 등록합니다.
  • 보기 모드 전환: [목록] 모드(컴팩트) 또는 [카드] 모드(큰 썸네일)를 자유롭게 선택할 수 있습니다.
  • 본문에 삽화 넣기:
    • 본문 에디터에서 이미지를 넣고 싶은 위치에 커서를 둔 뒤, 삽화 항목의 [+] 버튼을 누르면 [IMAGE:파일명.jpg] 태그가 자동으로 삽입됩니다.
    • PC 환경에서는 이미지를 마우스로 드래그하여 본문 에디터 원하는 줄에 직접 드롭(Drag & Drop)할 수도 있습니다.
[가이드 그림 2] 삽화 보관함 탭과 편리한 본문 태그 삽입 기능

4단계: 최종 출판 설정 및 EPUB 다운로드 (Publishing)

  • 우측 상단의 초록색 [전자책 생성] 버튼을 클릭합니다. (단축키: Ctrl + S)
  • 도서 메타데이터 입력:
    • 도서 제목: 전자책 뷰어에 표시될 책 제목을 입력합니다.
    • 작가명: 저자명을 입력합니다.
    • 출판사 & 작성일자: 출판사 및 발행 일자를 지정합니다.
    • 표지 이미지: [이미지 선택] 버튼을 눌러 멋진 책 표지를 등록합니다.
  • 맨 아래의 [전자책 작성 완료 (.epub 다운로드)] 버튼을 누르면 백그라운드에서 EPUB 3.0/2.0 표준 규격으로 패키징되어 내 기기로 즉시 저장됩니다.

💡 기기별 최적 조작 팁 (Device Tips)

  • 스마트폰 세로 모드: 20배 초대형 타이탄 스케일이 적용되어 한 손으로도 시원하게 조작할 수 있습니다. 하단 탭 바를 눌러 [본문 에디터 / 목차 목록 / 삽화 보관함]을 빠르게 오갈 수 있습니다.
  • 태블릿 가로 모드: 좌측 62% 본문 에디터와 우측 38% 목차/삽화 2단 와이드 스튜디오가 자동 활성화되어 넓은 화면을 효율적으로 활용할 수 있습니다.
  • PC 대화면 모드: 좌측 목차, 중앙 에디터, 우측 삽화의 3단 고정 스튜디오로 프로페셔널한 저작 작업을 수행할 수 있습니다.
