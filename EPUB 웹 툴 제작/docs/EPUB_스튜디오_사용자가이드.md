## 🚀 3분 완성 퀵 스타트 (Quick Start)

1. **원고 불러오기:** 상단의 `[📂 파일 불러오기]` 버튼을 눌러 TXT 파일을 엽니다.
2. **목차 자동 생성:** 본문에서 목차 패턴(예: `제1장 ...`)을 드래그한 후 `[✨ 목차 형식 분석]`을 클릭합니다.
3. **삽화 등록 (선택):** 삽화 보관함에서 이미지를 추가하고 본문에 `[IMAGE:파일명]`을 삽입합니다.
4. **전자책 출판:** 우측 상단의 `[전자책 생성]`을 눌러 도서 정보와 표지를 설정하고 `.epub` 파일을 다운로드합니다.

## 📖 상세 사용 방법

### 1단계: 원고 파일 불러오기
* 상단 툴바의 **[📂 파일 불러오기]** 버튼을 클릭하여 소장 중인 원고 TXT 파일을 선택합니다.
* **인코딩 자동 감지:** UTF-8, UTF-16, CP949(EUC-KR) 등 어떤 인코딩도 깨짐 없이 자동 변환합니다.
* **가상 뷰포트:** 80만 줄 이상의 대용량 원고도 1초 만에 로드되며 렉 없이 스크롤됩니다.

### 2단계: 목차 생성 및 관리
* **목차 형식 분석:** 본문에서 `제1장` 같은 문구를 드래그 후 **[✨ 목차 형식 분석]**을 누르면 전체 목차가 1초 만에 자동 생성됩니다.
* **수동 추가:** 특정 문구를 드래그 후 **[➕ 선택영역 목차 추가]**를 누르면 즉시 목차에 등록됩니다.
* **목차 탭 내부 서브 툴바:** `동기화`(줄 번호 재정렬), `개별 해제`(선택 삭제), `전체 삭제` 지원.
* 목차를 클릭하면 본문 해당 위치로 즉시 점프합니다.

### 3단계: 삽화(이미지) 등록 및 본문 배치
* 삽화 보관함의 **[+ 추가]** 버튼을 눌러 이미지(JPG, PNG, GIF, WebP 등)를 등록합니다.
* 본문 원하는 줄에 커서를 두고 삽화 항목의 **[+]**를 누르면 `[IMAGE:파일명.jpg]` 태그가 삽입됩니다.

### 4단계: 최종 출판 설정 및 EPUB 다운로드
* 우측 상단의 **[전자책 생성]** 버튼을 누릅니다. (단축키: `Ctrl + S`)
* 도서 제목, 작가명, 출판사, 발행일, 표지 이미지를 설정합니다.
* **[전자책 작성 완료 (.epub 다운로드)]** 버튼을 누르면 즉시 완벽한 EPUB 전자책이 다운로드됩니다.
